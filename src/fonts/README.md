# Switzer

Switzer, by the Indian Type Foundry, released through Fontshare under the ITF
Free Font Licence, which allows self-hosting for commercial work. The files
here are the latin subset, version 1.200, taken from the Fontsource build.

Three weights are carried, because the page uses three: 400 for body copy,
500 for headlines and card titles, 600 for the few places that need a little
more weight. Add a weight here and wire it up in `src/app/layout.tsx`.
